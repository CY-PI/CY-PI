## Computer Science @ UNSW

:feet: **COMP1511 - Programming Fundamentals**, 2023T1: Sasha was the course convenor. She is fun and a great teacher!
The course sets you up for your future in Computer Science, it is taught using C and you are only allowed to use the standard libraries.
I loved it, although the assignments are time consuming.

:fallen_leaf: **COMP2521 - Data structures and Algorithms**, 2023T2: extremely important course.
I was working full-time and taking a maths unit at the same time... I wish I had only taken this unit, so I could really dedicate more time to it.
It is a great course, good fun. I don't regret taking it after COMP1511, since it's a pre-requisite for many other courses. You need to get your labs marked, explaining to your tutor what you did.

:snowman: **COMP1531 - Software Engineering Fundamentals**, 2023T3: It is supposed to be an easy course, if you have a good group.
We basically had to deploy a web-based application, doing the backend programming. We learned how to use git and javascript.

**COMP2511 - Object-Oriented Programming**, 2024T1: It's all about the design patterns, which was something new to me. I enjoyed learning java.

**COMP3311 - Database Systems**, 2024T2: This course gives you an overview of databases and teaches the basics of PostgreSQL and Python for data retrieval. I wish they could teach you more advanced SQL in this course, 
which is required if you are going for any data-related jobs.

**COMP1521 - Computer Systems Fundamentals**, 2024T3: Andrew Taylor is the course convenor, I loved it. MIPS is a lot of fun and you also learn lots of other different concepts, important to understand how a computer works. 
It took me a while to take this unit, because I heard it was very hard. But I thought it was very good!

**COMP2041 - Software Construction**, 2025T1: I took this course because I knew Andrew Taylor was the course convenor. I didn't know what to expect and I ended up loving it.
You learn Shell at the first part of the course and Python and the second half. It is a very good course, gives you a view on how to automate processes and I wish I knew
these things years ago, when I started dealing with data and reporting... Great course! I can't comment on the workload since I was only taking this unit...
